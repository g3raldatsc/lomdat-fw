## Ringkasan

Repositori ini dirancang khusus bagi individu yang ingin berkompetisi di dunia Data Science dengan mengimplementasikan kerangka kerja standar industri, yaitu **CRISP-DM** (*Cross-Industry Standard Process for Data Mining*).

---

## Lebih Lanjut

**CRISP-DM** (*Cross-Industry Standard Process for Data Mining*) merupakan kerangka kerja standar industri yang secara luas digunakan oleh para praktisi data untuk mengelola dan mengimplementasikan siklus proyek Data Science maupun Data Mining secara komprehensif dari tahap awal hingga akhir.

Untuk mendukung pengerjaan kompetisi secara sistematis, repositori ini terbagi ke dalam beberapa direktori khusus:

1. **`0_GET-STARTED`**  
   Panduan awal dan langkah pertama untuk memulai pengerjaan proyek.
2. **`Catatan`**  
   Tempat untuk menyimpan berbagai dokumentasi ide, rincian eksperimen, serta catatan penting.
3. **`Dokumen`**  
   Penyimpanan berkas pendukung, seperti laporan, panduan kompetisi, atau presentasi.
4. **`Dataset`**  
   Direktori khusus penyimpanan data mentah (*raw data*) maupun data terproses (*processed data*).
5. **`Notebook`**  
   Berkas kode eksplorasi, pemrosesan data, hingga pemodelan (misalnya `.ipynb` atau script).
6. **`Model`**  
   Penyimpanan artefak model machine learning yang telah dilatih (*serialized models*).
7. **`Pengumpulan`**  
   Berkas hasil prediksi (*submission files*) yang siap diunggah ke platform kompetisi.
8. **`xLain-Lain`**  
   File atau artefak pendukung lainnya yang tidak tergolong pada kategori utama.

Setiap direktori di atas telah dilengkapi dengan panduan penggunaan serta template berkas yang relevan untuk mempermudah pengerjaan tantangan dalam kompetisi Data Science.
