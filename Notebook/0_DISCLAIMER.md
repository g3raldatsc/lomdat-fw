# DISCLAIMER

Folder Notebook adalah folder yang sudah disediakan notebook untuk 5 proses pada CRISP-DM. Pengerjaan kompetisi dapat dilakukan pada folder ini sesuai dengan tahapan yang sedang dikerjakan.

1. 1_business_understanding.ipynb = merupakan file ipynb untuk proses pertama dalam CRISP-DM. Business Understanding merupakan proses utama untuk memahami kebutuhan bisnis dan tujuan pengerjaan.
2. 2_data_understanding.ipynb = merupakan file ipynb untuk proses kedua dalam CRISP-DM. Data Understanding merupakan proses untuk mengumpulkan dataset, memahami dataset, dan mempersiapkan langkah kedepannya untuk diolah pada tahap selanjutnya.
3. 3_data_preparation.ipynb = merupakan file untuk proses ketiga dalam CRISP-DM. Data Preparation merupakan proses untuk melakukan pengolahan dataset yang sudah dipahami pada proses Data Understanding.
4. 4_modeling.ipynb = merupakan file untuk proses keempat dalam CRISP-DM. Modeling merupakan proses untuk melakukan eksperimen2 untuk menciptakan model yang paling optimal dengan prediksi terbaik, dan dilakukan setelah dataset yang sudah diolah sudah ada.
5. 5_evaluation.ipynb = merupakan file untuk proses kelima dalam CRISP-DM. Evaluation merupakan proses untuk menuliskan hasil dari pengerjaan, korelasi dengan Business Understanding, dan ringkasan beserta evaluasi dari seluruh tahap dan hasil pengerjaan.
